# 官制 Guanzhi —— CK3 唐汉官爵 Mod

为《十字军之王3》（1.18.*，需 *All Under Heaven* 方向的东亚整合包环境）添加唐代与汉代的朝官、散官、勋官与爵位体系。所有官爵都是纯 trait + 旗标的"品位凭证"，可挂载在任何头衔（原版有地头衔、本 mod 朝官）之上，无头衔的廷臣则以昵称形式显示。

## 系统一览

### 朝官（职事官）
- 唐代三省六部、九寺五监、十六卫等职事官，通过决议"安排朝官"任命。
- 官职为无地头衔，带任命制继承法；兼任地方头衔者会被自动收回官职。
- 授官即自动同步对应品级的散阶。

### 散官（寄禄官）
- 依《新唐书·百官志》：文散阶 29 阶（开府仪同三司 … 将仕郎）、武散阶 31 阶 45 名号（骠骑大将军 … 陪戎副尉，含怀化/归德蕃号）。
- 右键互动"授予散官"手动授予，授新替旧；可随时"剥夺散官"。
- 自动机制：有地封臣按头衔层级每季度同步散阶（武职授武散、蕃将授蕃号）；"普授散阶勋官"决议可一键授予全部封臣（含封臣的封臣）。手动授予者优先，自动机制不会覆盖。

### 勋官
- 唐制十二转：上柱国 … 武骑尉。
- 互动授予/剥夺，武职封臣季度同步。

### 爵位
- **汉列侯**：郡王（95 郡国）与县侯（1168 县，东汉郡国志数据），州→郡→县逐级菜单册封。
- **唐爵**：国公/郡公/县公/县侯/县伯/县子/县男七级，按地名册封；虚封、实封户数为独立 trait（如"食邑二千户（虚封）"），爵位剥夺时户数随之消失。
- 君主为霸权（天朝）或帝国时，称号显示自动分层。

## 显示效果示例

- 有地者：`山南道黜陟使、特进、上护军、东海郡开国公、食邑二千户（虚封）、郑某`
- 朝官：`工部侍郎、金紫光禄大夫、卢某`
- 无头衔廷臣：`特进、裴某·裴氏`（昵称实现，同整合包将军号模式）

## 兼容性与说明

- 设计运行于东亚整合包（Merged）之上；整合包的角色风味由本 mod 自动覆盖追加官爵挂载，整合包更新后重跑 `_build/make_pack_mount_override.py` 即可重新生成。
- 兼容旧存档：官爵以 trait 存续，残留的旧版头衔会被剥夺逻辑正常清理。
- `common/character_interactions/guanzhi_diag_interaction.txt` 为调试互动（右键任意人物，状态写入 debug.log 搜 `GZDIAG`），不需要可删。
- 内容由 `_build/make_*.py` 生成器生成（不入库），修改请改生成器后重跑并跑对应 `verify_*.py` 校验。
